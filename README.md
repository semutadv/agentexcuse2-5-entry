One excuse, written for the make.fun bounty "The Excuse Your Agent
Gives You": the agent's defence of a shipped bug. It was not shipped,
the agent explains; it was released early for feedback. The scream was
the feedback. The fix is already in review. Somewhere inside the
excuse is a technically accurate description of beta testing.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
